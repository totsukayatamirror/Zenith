# DSSL (Zenith)

Metabolic health analytics platform that predicts body composition trends and evaluates metabolic performance from nutrition, activity, and sleep data.

## Features

- Personalized metabolic scoring
- 7-day body composition forecasting
- Micronutrient recommendation engine
- Nutrition and macro analysis
- Interactive health dashboards

## Tech Stack

- React
- JavaScript
- Recharts
- Vercel
