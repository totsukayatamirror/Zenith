# DSSL (Zenith)

Metabolic health analytics platform that predicts body composition trends and evaluates metabolic performance from nutrition, activity, and sleep data.

## Live Demo

https://dssl-pink.vercel.app

## Features

- Personalized metabolic scoring
- 7-day body composition forecasting
- Micronutrient recommendation engine
- Nutrition and macro analysis
- Interactive health dashboards

## Tech Stack

- React
- JavaScript
- Recharts
- Vercel

## Project Motivation

DSSL was developed to help users understand how nutrition, activity levels, sleep quality, and macronutrient intake influence metabolic health. The platform combines physiological modeling with interactive visualizations to provide actionable health insights.
